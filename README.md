# Projetoacademia Frontend

> Frontend da aplicacao de academia desenvolvido com Next.js e React, com telas de login, listagem e gestao de alunos e planos.

## Stack

- Next.js
- Axios

## Prerequisitos

- Node.js v14+

## Como executar

```bash
# Clone o repositorio
git clone https://github.com/meirelesdev/projetoacademia-frontend.git
cd projetoacademia-frontend

# Instale as dependencias
npm install

# Inicie a aplicacao
npm run dev
```
